# 剧本生成

用"我给选项、你选、我汇总生成"的方式做短剧剧本。核心不是替用户想创意，而是把创意决策拆成可点的选项，让用户始终掌握方向权，最后一次性交付能直接用的完整文档。

## 何时使用

- 用户想做短剧/短视频剧本、微电影剧本、分集大纲
- 用户说"给我几个题材选选""帮我构思个剧本""想写个短剧"
- 已有模糊想法但没定方向，需要被推着做决定
- 用户主动点名"用剧本生成技能"/"按剧本生成流程来"

不适用：已有完整剧本需要润色改写、分镜表绘制、视频提示词生成（那些走别的流程）。

## 核心原则

1. **不空谈，先定骨架再动笔。** 绝不在选项确认前开始写正文。
2. **选项要能直接点，不开放填空。** 每问 2–4 个具体选项，每个选项带一句"选它意味着什么"的后果说明。
3. **两轮封顶。** 第一轮定骨架，第二轮定血肉，之后立刻生成。不要第三轮——选多了人就烦了。
4. **生成即完整。** 交付的是可拍的完整文档，不是大纲草稿，也不是"要不要继续"的追问。
5. **双格式交付。** Markdown 版用于编辑，TXT 纯文本版用于打印/导入剧本软件，内容必须等价。

## 工作流程

### 第 0 步：接住需求

用户说想写剧本时，不要立刻甩问题。先用一句话说明流程，让用户有预期：

> 想做短剧，先把骨架定下来再动笔，节奏会快很多。我按「题材 → 爽点 → 主角 → 篇幅」四步给你选项，你选完我再给你第二轮细节选项，最后一次性汇总成完整剧本大纲 + 分集。

### 第 1 步：第一轮 —— 骨架四问

用 AskUserQuestion，一次问满 4 个：

| # | 问题 | 选项（header ≤12字符） |
|---|---|---|
| 1 | 想走哪个题材赛道？ | 都市情感虐恋 / 悬疑反转复仇 / 甜宠爽文逆袭 / 奇幻穿越系统 |
| 2 | 主线靠哪个爽点撑住观众？ | 开局即爆点 / 身份反转掉马甲 / 绝境反杀 / 情感拉扯 |
| 3 | 主角视角怎么定？ | 女主独立逆袭 / 男主大佬追妻 / 双强相爱相杀 / 群像多线并行 |
| 4 | 打算做多长？ | 30集×1分钟 / 60集×1.5分钟 / 12集×3分钟 / 单集5-8分钟 |

每个选项的 description 必须写后果，不能只写名词。参考写法见 `references/选项库.md`。

**选完后先复述再进第二轮**，用一句话把选择压成故事方向，让用户确认方向没跑偏：

> 骨架有了：**悬疑反转复仇 + 开局即爆点 + 女主独立逆袭 + 30集×1分钟**。这个组合很对——30集超短剧最吃"前3秒钩子 + 每集一个反转"。

### 第 2 步：第二轮 —— 血肉四问

| # | 问题 | 选项 |
|---|---|---|
| 1 | 反派设成谁？ | 枕边人背叛 / 血亲夺产 / 上位者构陷 / 全员皆敌 |
| 2 | 反转怎么铺？ | 三幕大反转 / 每集小钩子 / 身份层层剥 / 罗生门多视角 |
| 3 | 结局走向？ | 爽文完胜 / 复仇代价 / 真相崩塌 / 开放式悬念 |
| 4 | 整体调性？ | 冷峻高级 / 快节奏爆点 / 暗黑狠戾 / 爽中带刀 |

### 第 3 步：汇总生成

八项都定完后**立刻生成完整文档**，不再追问。文档按 `references/输出模板.md` 的八章结构写。

生成时的硬要求：

- **开局钩子必须写在最前面且足够狠。** 前 3 秒定生死：黑屏 + 强音效 + 一句炸点台词/画面。这是全剧最强的投流素材，必须单独拎出来。
- **每集都要有尾钩。** 集数 = 反转数，尾钩是"新信息 + 新危机"，不能是重复悬念。
- **反派要有口头禅和行事逻辑。** 好人写得像人，坏人也得写得像人。
- **至少写一个隐藏真相 + 一个终极反转。** 隐藏真相在中后段揭（推翻女主对某人的认知），终极反转留到最后一集。
- **结局要真的落地。** 选了"开放式悬念"就得留能接第二季的具体钩子（新人物/新身份/新威胁），不能停在"未完待续"。

### 第 4 步：双格式交付

1. 先写 `.md`（主版本，表格用 Markdown 语法）
2. 再写 `.txt`（纯文本版：去掉 `#`、`**`、`|`，表格改缩进条目，标题用 `=` / `-` 分隔线）
3. 两份内容必须等价，改剧情时同步维护
4. 用 present_files 一起呈现

TXT 版不是改后缀，要重新排版——表格在纯文本里会散架。

### 第 5 步（可选）：可视化

用 show_widget 画一张分幕结构图 + 集数刻度条，标注付费点位置。对 20 集以上的剧本特别有用，用户一眼能看到节奏。

## 儿童向改编规则

用户说"适合儿童/低龄/幼儿园/小学生"时，前四步流程不变，但做这些替换：

| 成人向 | 儿童向替换 |
|---|---|
| 反派设定 | 麻烦源（捣蛋小伙伴 / 自然小麻烦 / 误会 / 反面习惯怪兽）——**不能有真反派** |
| 结局走向 | 温暖收束 + 第二季任务解锁，不用"真相崩塌"这类 |
| 每集收获 | 一个能立刻动手做的技能/动作，不是情绪 |
| 付费点 | 追更钩（情感节点集数），儿童内容不做付费卡点 |

**儿童向四问见 `references/选项库.md` 末尾**。题材换成童话奇幻/科普启蒙/校园友情/萌宠日常，篇幅优先 12集×3分钟 或 20集×2分钟（1分钟太碎，撑不住故事）。

三条硬约束：

1. **危险动作必须专业演示并打"请勿模仿"角标**，不做可完整模仿的示范（火、水、高处尤其严格）
2. **知识点要专业审校**（医疗、消防、急救），这是能不能进校园的门槛
3. **隐患要真，画面不可怕**——控制在"紧张"而非"惊吓"，低龄观众承受力低

儿童向还需要额外写：未成年演员拍摄合规、家长版说明书、可下载的配套互动材料、政务号/教育机构发行路径。

## 短剧写作铁律

写 60 秒一集时死守这个时间分配：

| 时间 | 内容 |
|---|---|
| 0–5 秒 | 钩子（画面冲击或一句话炸点） |
| 5–45 秒 | 只推**一件**事，不塞第二条线 |
| 45–58 秒 | 反转或危局 |
| 58–60 秒 | 硬切黑屏 + 下一集标题，不留缓冲 |

其他规则：

- **付费点**卡在每一幕的第一个大反转落地的那集（如四幕剧 → 第 8 / 16 / 24 集）
- **场景复用**：20–30 集只需要 5 个主场景换灯换机位就能撑住
- **配乐分幕**：前期不铺旋律（悬疑），中期提速加心跳，后期加人声，大结局全部撤掉留环境音
- **切片素材**：在文档里直接标出哪 3–4 个片段适合投流

## 常见坑

- **别在选项里塞抽象词。** "深刻的""有张力的"这类没法选，要写成"反派是枕边人，仇恨最私人"这种能想象的后果。
- **别问第三轮。** 八项够了，剩下的细节在生成时自己拍板，写完告诉用户"这几处我按 X 处理了，可以改"。
- **别写"未完待续"当结局。** 开放式不等于没写，要给具体的钩子画面。
- **别只给大纲不给样稿。** 至少写一集完整台词（带秒数和镜头），用户才知道质感对不对。
- **表格转 TXT 要重排。** 直接改后缀会毁掉可读性。

## 示例

用户输入："我想创作一个短剧剧本，有什么好的题材吗，让我跟你交互的，你给我选项我选，在汇总生成"

执行：说明流程 → 第一轮四问 → 复述确认 → 第二轮四问 → 生成《第七张脸》30集完整剧本（md + txt）→ 四幕结构可视化图 → present_files
